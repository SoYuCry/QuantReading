# AFT 2025 阅读笔记：Prediction Market Arbitrage

论文：*Unravelling the Probabilistic Forest: Arbitrage in Prediction Markets*

原文：`Papers/PolymarketMM/2025aft-arbitrage.pdf`

## 核心问题

论文研究 Polymarket 中两类价格矛盾：

1. **市场再平衡套利**：同一个 Event 内，互斥结果的价格没有满足加总约束。
2. **组合套利**：两个 Event 中逻辑等价的结果组合价格不同。

它尝试回答：套利为什么出现、历史上是否出现、是否有人实际提取利润。

## 术语校正

论文术语与 Polymarket 官方数据模型错位：

| 论文术语 | 官方术语 |
|---|---|
| Market | Event |
| Condition | Binary Market / CTF Condition |
| YES / NO | Outcome Tokens |

阅读公式时，应把论文中的 $M=\{C_1,\ldots,C_n\}$ 理解成“一个 Event 包含多个二元 Market”。

## 两个基本套利约束

单个二元 Market：

```text
YES + NO = 1
```

多结果 Event：

```text
所有互斥结果的 YES 价格之和 = 1
```

跨 Event 组合套利本质上是一价定律：如果命题 A 与命题 B 在所有有效结算状态下等价，那么它们的价格也应该相同。若 A 更便宜，可构造“买入 A + 买入 NOT B”。

## 方法流程

```text
文本嵌入按主题和日期缩小候选范围
→ LLM 推断两个 Event 的可能联合结算状态
→ 确定性程序寻找等价结果子集
→ 人工核对候选关系
→ 使用链上成交事件估算套利机会和套利者利润
```

LLM 更适合做候选生成器，而不是最终套利裁判。美国大选样本中，LLM 最初标记 1,576 对依赖候选，论文最终只声称 13 对满足严格组合套利定义。

## 有价值的部分

- 强调预测市场的资产同一性取决于自然语言结算规则，而不只是 ticker。
- 区分单二元 Market、多结果 Event、跨 Event 三个套利层级。
- 把语义关系转换为确定性的支付约束，研究方向有启发性。
- 提醒我们：逻辑上无风险，不代表建仓过程无风险；Polymarket 多腿交易通常是非原子的。

## 主要方法问题

1. **历史成交 VWAP 不是可执行报价**：不能证明同一时刻能够按这些价格买到所有腿。
2. **价格不同步**：旧成交价最多延续约 2.5 小时，再与其他 token 的当前成交价相加。
3. **无成交被设为 0**：没有成交不等于价值为零，更不等于可以零成本买入。
4. **缺少订单簿深度**：token 存量不等于当前可成交数量。
5. **忽略低于 2% 的结果**：一旦没有覆盖所有结果，策略就不再是严格无风险套利。
6. **一小时地址窗口可能误配交易**：时间接近不代表多笔成交属于同一套利策略。
7. **地址不等于真实交易者**：一个实体可能控制多个地址，合约也可能代表多个用户。
8. **论文存在多处数字和公式不一致**：包括 $n+m$ 与 $n\times m$、4 对候选与 11 对人工确认、13 对与图中的 11 对等。

“全部单二元机会都是 Long”“组合成本中位数约 0.60”等结果，很可能受到陈旧价格和零值填充的系统性向下偏差影响。

## 4000 万美元结论的构成

论文报告的利润大致为：

| 类型 | 报告金额 |
|---|---:|
| 单个二元 Market 内 | 约 1,058 万美元 |
| 多结果 Event 内 | 约 2,902 万美元 |
| 跨 Event 组合套利 | 约 9.5 万美元 |

真正依赖 LLM 语义分析的跨 Event 部分，只占 headline 金额约 0.24%。绝大部分所谓利润来自不需要 LLM 的简单价格加总约束，而且多结果部分混入了未完整覆盖所有结果的策略。

## 最终评价

> 选题很好、叙事很强，但测量方法与结论强度不匹配。

它没有充分证明大规模、可执行、无风险的套利，更适合作为预测市场套利研究的概念起点和反面方法案例。

## 留给下一篇论文的问题

下一篇重点检查：

- 是否拥有同步的历史 LOB 快照；
- 是否使用 best bid / best ask，而不是成交均价；
- 是否逐档计算可执行数量和滑点；
- 是否把连续多个快照合并为一次 episode；
- 是否区分理论价差、可执行机会和实际成交利润；
- 是否考虑非原子执行、手续费和低流动性。
